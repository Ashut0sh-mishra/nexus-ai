## NEXUS vs Field: Gap Analysis

### Critical Gaps (Score Impact > 5 points each)

1. **No planner/executor agent loop** — Every serious agent framework (OpenManus, Suna, AgenticSeek) has one. NEXUS runs basic Celery tasks with no planning, step tracking, or retry logic. This is the single largest gap.

2. **No generation API** — Presenton has a full REST API. NEXUS generates slides via UI only. This blocks eval automation, external integration, and MCP exposure.

3. **No multi-LLM provider support** — Presenton supports 6+ providers via env vars. Suna uses LiteLLM for 100+. NEXUS appears hardcoded to one provider.

4. **No template import** — Both Presenton and PPT Master can import any .pptx as a template. NEXUS has only built-in canonical layouts.

5. **Live eval never completed** — The benchmark harness exists but live eval has never run at scale. No proven score. No regression baseline.

### Moderate Gaps (Score Impact 2-4 points each)

6. No browser automation for research/citations
7. No async job progress streaming
8. No MCP server or consumer
9. No cost/token tracking
10. No visual export parity verification

### Minor Gaps (Score Impact 1-2 points each)

11. No action trace recording
12. No deterministic replay for benchmarks
13. No rate limits or quotas
14. No multi-tenant isolation
15. No PDF export (status unknown)
