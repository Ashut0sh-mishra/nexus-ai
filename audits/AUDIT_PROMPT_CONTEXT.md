# NEXUS AI — Prompt Context Block

Paste this block (or its key facts) into any new Opus / AI chat working on NEXUS AI. It establishes the rules of the workspace and the current accepted state.

---

## Project Scope

- We are working on **NEXUS AI only**.
- `manus-need/` and `manus-reference/` are **reference material only**. Do not modify. Do not assume their behaviour applies to NEXUS.
- Code lives under `nexus-ai/backend/`, `nexus-ai/frontend/`, `nexus-ai/scripts/`. Audits live under `nexus-ai/audits/`.

## Roles

- **Copilot** is the **auditor and tester**. Copilot writes prompts, reviews diffs, runs verification, and accepts/rejects phases. Copilot does not implement features.
- **Opus** is the **implementer**. Opus reads the current state, executes one focused phase prompt, and updates the audit files.

## Workflow Per Phase

1. Copilot writes **one focused prompt** for the next phase, scoped narrowly.
2. Opus implements the phase. Only the files described in the prompt should change.
3. Opus updates the audit files with a new dated phase section.
4. Copilot audits the diff, runs verification, and reports Pass / Partial / Fail.
5. The next phase prompt is written **only after** the previous phase has a recorded result.

- **Date / time.**
